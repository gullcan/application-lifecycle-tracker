# Application Lifecycle Tracker 1.1.0

Version 1.1 completes the project as a local-first personal job application manager.

## Highlights

- Edit company, position, source, job URL, and personal notes
- Search application content and sort by creation date or company
- Archive and restore records without deleting lifecycle history
- Export all active and archived applications as CSV
- Create consistent SQLite backups and restore a selected backup
- Run a full-stack Playwright workflow against an isolated Docker Compose environment

## Quality evidence

- 141 backend tests
- 96%+ backend statement and branch coverage
- 6 frontend component tests
- Ruff static analysis and strict mypy checks
- React production build and two non-root container images
- Browser-verified React–NGINX–FastAPI–SQLite workflow

## Product scope

This release is intended for one user running the application locally. Authentication, public hosting, PostgreSQL, and multi-user features are intentionally outside scope.
